# Fictional facility plugin

This deliberately invented example accepts a small JSON facility plan. Its
source, package, item, connection, and segment identifiers are explicit and
stable, so record order does not affect reimport identity.

The example is contract documentation, not an integration with any real
product or organization. It includes a bounded JSON summary exporter and
contains no network conventions, document layout, service URL, credential
handling, or private source mapping.
