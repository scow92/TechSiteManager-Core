# Security policy

Do not open a public issue for a suspected vulnerability, credential, or
private-data disclosure. Until a dedicated security contact is configured,
use GitHub's private vulnerability reporting feature for this repository.

Do not include secrets, source records, internal locations, or exploit data
beyond what is necessary to reproduce the issue safely. Plugin packages are
trusted in-process application code and require the same review, pinning, and
supply-chain controls as core.
