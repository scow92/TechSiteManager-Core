# Publication approval checklist

This checklist separates owner decisions already provided from the human
reviews and publication authority that remain outstanding. Codex assembled
the evidence but is not a human approver.

## Recorded owner decisions

- [x] The owner confirmed ownership of the candidate's original code.
- [x] The owner selected Apache License, Version 2.0 (`Apache-2.0`) as the
  outbound licence and identified Copyright 2026 Sam Cowie.

These decisions authorize the licence files and pre-publication validation.
They do not authorize merging, changing visibility, publishing a package or
image, creating a release, or renaming either repository.

## Human approvals still required

- [ ] Technical review completed by an authorized human reviewer.
- [ ] Security review completed, including any organization-mandated external
  scanner results.
- [ ] Copyright and intellectual-property review completed.
- [ ] Third-party licensing and attribution review completed.
- [ ] Disclosure review completed, including Git author metadata.
- [ ] Final publication approval granted.
- [ ] Explicit approval granted for merging the private pull request.
- [ ] Explicit approval granted for the later public-visibility step and an
  acceptable public repository name.

Record approver identity, date, evidence reference, and any conditions in the
private approval system used by the owner or organization. Do not add private
review findings or sensitive disclosure patterns to this public candidate.
